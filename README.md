The Mood-Based Music Recommender System is an intelligent application that recommends music tracks based on a user’s current emotional state. It leverages facial emotion recognition or textual input (like user mood selection) to analyze the user's mood and suggest songs that align with or uplift their emotional state.

✅ Key Features
Detects user's mood using facial expressions (via webcam) or manual input

Classifies emotions such as Happy, Sad, Angry, Neutral, etc.

Recommends songs that match the detected mood from a curated music dataset

Option to auto-play songs or open them on platforms like YouTube/Spotify

Simple and intuitive GUI for easy interaction

💡 Use Cases
Personalized music therapy for mood regulation

Enhancing user experience through emotionally aware music suggestions

Demonstrates integration of computer vision, machine learning, and recommendation systems

📁 Technologies Used
Python

OpenCV (for face detection)

Deep Learning / CNN model (for emotion recognition)

Tkinter / Streamlit (for GUI)

Pandas & NumPy

SQLite / CSV for music database
